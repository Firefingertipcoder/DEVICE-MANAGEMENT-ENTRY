# 💻 DEVICE MANAGEMENT ENTRY

A professional Desktop Application built with Python and Tkinter for managing computer hardware inventories, users, and device lifecycles.

## 🚀 Features
- **Secure Authentication**: Integrated Login and Profile Registration.
- **Inventory Management**: Track categories, models, and technical specs (RAM, CPU, SSD).
- **Data Integrity**: Uses SQLite with Unique Serial constraints.
- **Reporting**: Export your entire asset list to professional CSV reports.
- **Responsive Design**: Modern UI with a side-navigation layout.

## 🛠️ Technology Stack
- **Language**: Python 3.x
- **GUI Library**: Tkinter (Standard Library)
- **Database**: SQLite3
- **Reports**: CSV Module
